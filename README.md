# Automatizacion QA - Saucedemo

Proyecto de automatizacion de pruebas realizado con python para curso de Talemto tech.

## Tecnologias utilizadas
- Python
- Selenium
- Pytest
- Git
- Github

## Instalacion


    ``` python
    pip install selenium
    ```

    ``` python
    pip install pytest
    ```

    ``` python
    pip install pytest-html
    ```

## Ejecutar pruebas
    ```python
    pytest
    ```


## Casos de prueba

- Login test
- Agregar producto al carrito
- Verificar producto al carrito
